我的行程

也可以直接點頁首行程名稱旁的切換按鈕快速換行程。所有變更都會自動寫入雲端，頁首會顯示同步狀態；如果別人剛好也改過，會先自動合併，無法合併時才會詢問你。

建立新行程

你會是這個行程的建立者，也是第一位成員。之後可以到「成員與分享」邀請朋友，或到「行程」綁定 Discord 伺服器。

下載備份

行程的資料都存在雲端，平常不需要另外備份；想自己留一份，或要搬到別的地方時，可以下載成 JSON 檔。

匯入成新行程

選擇之前下載的 JSON 檔（或直接貼上內容），會建立成一個新的雲端行程，不會動到目前開著的行程。匯入時會問你是裡面的哪一位成員。
